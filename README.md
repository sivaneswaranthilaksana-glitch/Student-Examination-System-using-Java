# 🎓 Student Examination System

A **Java-based Student Examination System** developed as a **group project** for a university academic project. The system demonstrates fundamental **Object-Oriented Programming (OOP)** concepts while providing a simple console-based solution for managing examination eligibility, GPA calculation, and class determination.

## 📌 Project Overview

The Student Examination System is designed to evaluate students based on their **attendance, ICA marks, and examination results**.

The system checks whether a student is eligible to sit for the examination, calculates the student's **GPA**, and determines the appropriate **class** based on the GPA.

## ✨ Key Features

* ✅ Examination eligibility checking based on attendance and ICA marks
* 📊 GPA calculation using grades and credit values
* 🎓 Class determination based on GPA
* 🖥️ Menu-driven console interface
* 👨‍💻 Object-Oriented Programming implementation
* 🔢 Array-based data handling
* ⌨️ User input using `Scanner`
* 🔀 Conditional statements for decision-making

## ⚙️ System Process

The system generally follows these steps:

1. Enter student information.
2. Enter attendance and ICA marks.
3. Check examination eligibility.
4. Enter examination grades and credit values.
5. Calculate the student's GPA.
6. Determine the student's class based on the GPA.
7. Display the final results.

## 🧩 OOP Concepts Used

This project applies several important Java OOP concepts, including:

* **Classes** – Used to represent different entities and organize the program structure.
* **Interfaces** – Used to define common behaviors and support abstraction.
* **Methods** – Used to divide the program into reusable components.
* **Objects** – Used to work with class-based data and functionality.
* **Encapsulation** – Used to organize and manage data within classes.
